# kosdaq_ti

코스닥150 지수에 Shynkevich et al. (2017, *Neurocomputing*) **"Forecasting price movements using technical indicators: Investigating the impact of varying input window length"** 를 적용한 실험입니다.

논문은 10개 기술지표를 모두 같은 입력 윈도우 n으로 계산해 SVM · ANN · kNN으로 s일 뒤 가격 방향을 맞히고, 예측기간 s × 입력 윈도우 n 격자에서 **"n ≈ s일 때 성능이 가장 좋다"** 는 패턴을 보고합니다(S&P 500 종목 50개, 학습 1740일 · 평가 900일).

코스닥150은 종가가 2010-01-04부터, 시가·고가·저가가 2015-07-13부터만 있습니다. 그래서 고가·저가가 필요한 지표를 **종가만으로 계산하는 버전**(고가 = 저가 = 종가)을 만들어 학습 기간을 2010년까지 늘리고, OHLC 원식과 비교합니다.

## 실행

```bash
pip install -r requirements.txt
python run_ti_forecast.py data/kosdaq150.xlsx                       # 그리드(논문 Table III–X) + walk-forward
python run_ti_forecast.py data/kosdaq150.xlsx --models svm --skip-wf  # 그리드만, SVM만
python run_ti_forecast.py data/kosdaq150.xlsx --scenarios close_long --skip-grid --cost-bps 5
python run_ti_forecast.py data/kosdaq150.xlsx --models rf,xgb,lgbm,logit,arima  # 트리 계열 · 계량 모형
python run_ti_forecast.py data/kosdaq150.xlsx --models all --ann-backend torch --device cuda --svm-backend cuml  # GPU
python run_ti_forecast.py data/kosdaq150.xlsx --freq W               # 주간 (일간 입력을 주간으로 바꿈)
python run_learning_curve.py data/kosdaq150.xlsx                     # 학습 곡선: 학습 1·2·3·5·7·10년 비교
python run_learning_curve.py data/kosdaq150.xlsx --freq W --train-years 1,2,3,5,8
pytest tests                                                         # 지표 식 · 미래 정보 미사용 · 분할 규칙
```

`--models` 기본값은 논문의 `svm,ann,knn`입니다. 트리 계열 · 계량 모형은 선택 패키지가 필요합니다(`pip install xgboost lightgbm statsmodels`, ANN torch 백엔드는 `torch`, GPU SVM은 RAPIDS `cuml`). 없는 패키지를 쓰는 모델을 고르면 시작할 때 설치 명령을 알려 줍니다.

입력은 DataGuide 엑셀(메타데이터 줄 뒤 `D A T E | 저가지수 | 고가지수 | 시가지수 | 종가지수`)이나 `date, open, high, low, close` csv입니다. 시가·고가·저가가 없는 날은 비워 두면 됩니다.

전체 실행(3 시나리오 × 9 예측기간 × 8 윈도우 × 2/3 클래스 × 3 모델 = 1,296개 학습 + 연도별 walk-forward)은 4코어에서 2~3시간 걸립니다. 대부분 SVM 격자 탐색(110개 조합 × 5 fold)이며, 끝난 학습은 `out/.../cache/`에 저장되어 다시 실행하면 재사용합니다.
추가 모델은 모델마다 그리드 432개(ARIMA는 윈도우와 무관해 54개) + walk-forward 약 540개 작업이라, 아래 [속도 · GPU](#속도--gpu) 표의 1회 학습 시간 × 작업 수 ÷ 코어 수로 어림할 수 있습니다.

## 기술지표 (모두 같은 입력 윈도우 n)

| 지표 | OHLC 원식 | 종가 전용 (H = L = C) |
|---|---|---|
| SMA | C / SMA_n(C) − 1 | 같음 |
| EMA | C / EMA_n(C) − 1 | 같음 |
| ATR | Wilder_n(TR) / C | Wilder_n(\|ΔC\|) / C |
| ADX | Wilder_n(DX), DX = 100\|DI⁺ − DI⁻\|/(DI⁺ + DI⁻) | DM = max(±ΔC, 0) |
| CCI | (TP − SMA_n TP) / (0.015 · 평균편차), TP = (H+L+C)/3 | TP = C |
| ROC | C_t / C_{t−n} − 1 | 같음 |
| RSI | 100 · 상승 / (상승 + 하락), Wilder 평활 | 같음 |
| Williams %R | −100 (HH_n − C) / (HH_n − LL_n) | HH, LL = n일 최고·최저 종가 |
| Stochastic %K | 100 (C − LL_n) / (HH_n − LL_n) | 〃 |
| Stochastic %D | EMA_3(%K) | 〃 |

종가 전용 버전은 따로 만든 지표가 아니라, 같은 식에 고가 = 저가 = 종가를 넣은 것입니다. SMA · EMA · ROC · RSI는 원래 종가만 씁니다. 평활은 논문이 쓴 TA-Lib처럼 ATR · RSI · DI · ADX는 Wilder(α = 1/n), EMA는 α = 2/(n+1)입니다.

## 실험 설계

**시나리오** — 셋을 같은 평가구간에서 비교해 지표 종류와 학습 기간의 효과를 나눠 봅니다.

| 시나리오 | 지표 | 학습 시작 | 비교 |
|---|---|---|---|
| `ohlc_short` | OHLC 원식 | 2015-07 (+ warmup 120일) | 논문 그대로 |
| `close_short` | 종가 전용 | `ohlc_short`와 같은 날짜 | 지표 종류만 바꾼 효과 |
| `close_long` | 종가 전용 | 2010-01 (+ warmup 120일) | 학습 기간을 늘린 효과 |

**그리드 (논문 Table III–X)** — 평가구간은 OHLC 표본의 마지막 1/3(논문 2:1, `--test-frac`)이고, 세 시나리오 모두 같은 평가일입니다. s ∈ {1, 3, 5, 7, 10, 15, 20, 25, 30} × n ∈ {3, 5, 7, 10, 15, 20, 25, 30} × 2 클래스(Up/Down) · 3 클래스(Up/No Move/Down) × 모델마다 한 번 학습해 평가구간 전체를 예측합니다. 3 클래스 기준값 δ는 학습구간 |s일 수익률|의 1/3 분위수입니다(논문 Table I과 같은 기준: 클래스마다 약 1/3).

**walk-forward** — 매년 첫 거래일에 그 전까지 레이블이 확정된 표본으로 다시 학습해 그 해를 예측합니다. 입력 윈도우는 논문의 결론대로 n = s(s < 3이면 3)로 고정하므로, 평가구간을 보고 윈도우를 고르는 일이 없습니다. 첫 재학습은 표본 시작 약 3년 뒤(`close_long` 2013년, OHLC 시나리오 2019년)이고, `*_common` 파일은 세 시나리오를 2019년 이후 같은 구간에서 비교합니다.

**모델 (논문 Sec. 5.5)**
- SVM: sigmoid 커널, γ ∈ {2⁻¹⁵, 2⁻¹³, …, 2³} × C ∈ {2⁻⁵, 2⁻³, …, 2¹⁵}를 5-fold 교차검증 정확도로 선택
- ANN: 입력 10 – 은닉 10(tanh) – softmax, 학습구간 뒤 25%로 early stopping, `--ann-seeds`(5)개 시드의 확률 평균
- kNN: k ∈ {1, …, 10}을 5-fold 교차검증 정확도로 선택

**추가 모델 (논문에는 없음, 비교용)** — 트리 계열과 로지스틱 회귀는 같은 10개 지표 · 같은 표준화 · 같은 purged k-fold로 하이퍼파라미터를 고르므로 논문 모델과 바로 비교됩니다.

| `--models` | 모델 | 입력 | 하이퍼파라미터 (purged 5-fold 정확도로 선택) |
|---|---|---|---|
| `rf` | 랜덤 포레스트 200그루 (sklearn) | 지표 10개 | max_depth ∈ {3, 6, 제한 없음} × min_samples_leaf ∈ {5, 20, 80} |
| `xgb` | XGBoost (hist) | 지표 10개 | max_depth ∈ {2, 3, 5} × 학습률 ∈ {0.03, 0.1} × 나무 수 ∈ {50, 100, 200, 400} |
| `lgbm` | LightGBM | 지표 10개 | `xgb`와 같은 격자 (num_leaves = 2^max_depth) |
| `logit` | 로지스틱 회귀 (L2, 3 클래스는 다항 로짓) | 지표 10개 | C ∈ {10⁻³, …, 10²} |
| `arima` | 로그가격 ARIMA(p, 1, q) + 상수 | 일간 로그수익률 | (p, q) ∈ {0, 1, 2}²를 AIC로 선택 |

- 부스팅의 나무 수는 fold마다 400그루를 한 번 학습한 뒤 앞쪽 50 · 100 · 200그루로도 예측해 고르므로, 나무 수 후보를 늘려도 학습 횟수는 같습니다.
- `arima`는 지표를 쓰지 않습니다. 같은 학습 기간의 일간 로그수익률(평가 시작 전날까지)로 계수를 한 번 추정하고, 평가일마다 그날까지의 수익률로 s일 누적수익률을 예측해 레이블 규칙(2 클래스: > 0, 3 클래스: ±δ 밖)으로 방향을 정합니다. 입력 윈도우 n과 무관하므로 그리드에서는 한 번만 계산해 모든 n 칸에 같은 값을 넣습니다(히트맵에서 가로로 같은 색). 일간 수익률의 자기상관이 작으면 s일 예측이 거의 평균 수익률 × s라, 2 클래스는 대부분 평균의 부호 쪽(평균이 양수면 Up), 3 클래스는 대부분 No Move가 됩니다. 거래가 없는 칸은 승률 · Sharpe가 비어 있습니다.

**성과**
- 논문 지표: 매 평가일 Up → s일 매수, Down → s일 매도, No Move → 거래 없음. 정확도, 승률, 거래당 수익률, Sharpe = √(252/s) · 평균 / 표준편차(무위험금리 0). 겹치는 s일 거래를 독립으로 세므로 낙관적입니다. `acc_se`는 겹침을 감안한 정확도 표준오차 근사 √(p(1−p)/(N/s))입니다.
- tranche 포트폴리오: 매일 신호의 1/s를 s일 보유하는 겹치는 포지션으로 일간 수익률을 만들고, 신호 다음 날 종가에 체결(`--delay 1`)하며, 비중 변화 1당 10bp(`--cost-bps`)를 뺍니다. 롱숏(논문)과 롱온리(Up일 때만 매수) 두 가지로 CAGR · Sharpe · MDD를 계산합니다.
- 비교 기준은 같은 기간 Buy & Hold입니다.

## 속도 · GPU

학습 한 번에 걸리는 시간(1코어, 학습 3,109일 · 평가 871일 · 3 클래스, 합성 데이터)입니다. 작업끼리는 `--n-jobs`개 프로세스로 병렬 실행됩니다.

| 모델 | 1회 학습 | 비고 |
|---|---|---|
| `svm` | 약 106초 | 110개 조합 × 5 fold. 전체 실행 시간의 대부분 |
| `rf` | 약 32초 | |
| `xgb` | 약 23초 | 3 클래스는 라운드마다 나무 3그루 |
| `lgbm` | 약 14초 | |
| `ann` | 약 2.5초 (torch 약 1.2초) | |
| `arima` | 약 2초 | 같은 학습 표본은 프로세스 안에서 다시 맞추지 않음 |
| `knn`, `logit` | 1초 안팎 | |

가속 옵션:

| 옵션 | 효과 |
|---|---|
| `--ann-backend torch` | 시드 5개를 가중치 텐서 하나로 묶어 한 번에 학습합니다. CPU에서도 2배쯤 빠르고, `--device cuda`면 GPU에서 돌립니다. 구조 · 학습 규칙(Adam, minibatch 200, L2 10⁻⁴, 같은 early stopping)은 같지만 초기값 난수와 2 클래스 출력층(softmax 2개 vs logistic 1개)이 달라 결과 숫자가 sklearn과 조금 다릅니다. |
| `--device cuda` | `xgb`를 GPU에서 학습합니다(`device="cuda"`). |
| `--svm-backend cuml` | RAPIDS cuML의 GPU SVC로 같은 γ × C 격자를 탐색합니다. sklearn 경로는 커널 행렬을 미리 계산해 재사용하고, cuML 경로는 SVC가 커널을 직접 계산합니다(같은 격자 · 같은 fold. 테스트에서 sklearn으로 두 경로가 같은 답을 내는지 확인). |
| `--gpu-jobs` | GPU 작업을 동시에 돌릴 프로세스 수(기본 1). GPU 작업을 먼저 이만큼 병렬로 돌리고, 나머지 CPU 작업을 `--n-jobs`개로 돌립니다. |

- GPU를 쓰는 옵션을 골랐는데 CUDA GPU가 보이지 않으면 바로 멈춥니다(XGBoost는 GPU가 없으면 경고 없이 CPU로 돌기 때문입니다).
- 표본이 작아서(최대 약 3,100일 × 지표 10개) GPU는 큰 데이터에서만큼 빨라지지 않습니다. 커널 실행 · 데이터 복사 고정비가 학습 시간과 비슷하기 때문입니다. 가장 확실한 가속은 코어 수(`--n-jobs`)와 캐시입니다. GPU 경로(`--device cuda`, `--svm-backend cuml`)는 GPU가 없는 환경에서 만들어 GPU에서는 아직 실행해 보지 않았습니다.
- 캐시: backend · device가 기본값(sklearn · cpu)이 아니면 캐시 파일 이름에 붙습니다(`..._torch.pkl`, `..._cuda.pkl`). 기본 설정의 캐시 이름은 예전과 같아서, 이미 돌려 둔 SVM · ANN · kNN 결과를 그대로 다시 씁니다.

## 주간 데이터 (`--freq W`)

`--freq`는 `auto`(기본, 입력 날짜 간격의 중앙값이 4일 이상이면 주간), `D`, `W` 중 하나입니다. `W`에 일간 입력을 주면 월~금 한 주로 묶어 주간 가격을 만듭니다. 날짜는 그 주 마지막 거래일, 시가는 첫 거래일 시가, 고가·저가는 주중 최고·최저, 종가는 마지막 거래일 종가입니다. 주중 하루라도 시가·고가·저가가 없으면 그 주는 종가 전용으로 둡니다. 주간 파일을 직접 넣어도 됩니다(`auto`가 주간으로 인식하고, `--freq D`로 주면 멈춥니다).

주간이면 예측기간 · 윈도우 · warmup · 진입 지연(`--delay`)이 모두 **주 단위**이고, 연율화(Sharpe · CAGR · 변동성 · 회전율)는 252 대신 52를 씁니다. 지정하지 않은 값은 주기별 기본값을 씁니다.

| | 일간 (`D`) | 주간 (`W`) |
|---|---|---|
| 예측기간 s | 1, 3, 5, 7, 10, 15, 20, 25, 30일 | 1, 2, 3, 4, 6, 8, 13주 |
| 입력 윈도우 n | 3, 5, 7, 10, 15, 20, 25, 30일 | 3, 4, 6, 8, 10, 13, 20주 |
| warmup | 120일 | 60주 (Wilder n = 20 초기값 비중 약 5%) |
| 1년 | 252 | 52 |

주간으로 바꾸면 표본이 1/5로 줄어듭니다(코스닥150 종가 기준 약 4,000일 → 약 850주, OHLC 구간 약 590주). 그래서 평가구간의 정확도 표준오차가 1주 예측에서도 약 4%p, 4주 예측에서는 약 8%p입니다. 같은 기간을 예측한다면 독립 표본 수는 일간 데이터에서 s = 5로 예측할 때와 거의 같고, 학습 행 수만 줄어듭니다. 주 단위 예측이 목적이라면 일간 데이터에 `--horizons 5,10,20`처럼 주는 쪽이 보통 낫습니다. 이 차이는 아래 학습 곡선으로 직접 비교할 수 있습니다.

## 학습 곡선 (`run_learning_curve.py`)

학습 데이터가 얼마나 있어야 하는지 보려고, **같은 평가구간**에서 학습 기간만 바꿔 walk-forward 성과를 비교합니다.

- 매년 첫 표본 날짜에 **최근 k년**(rolling, `--train-years`, 기본 1, 2, 3, 5, 7, 10)으로 다시 학습해 그 해를 예측합니다. 입력 윈도우는 n = s입니다.
- 평가 첫해는 가장 긴 학습 기간이 표본 안에 들어가는 해입니다(`--eval-start-year`로 바꿀 수 있음). 그래서 학습 기간마다 평가일이 같습니다. 기본 시나리오는 표본이 가장 긴 `close_long`(`--scenario`)이고, 기본 모델은 빠른 `logit,knn,ann`입니다(SVM은 `--models`로 추가).
- 3 클래스는 δ를 학습구간에서 정하므로 학습 기간마다 평가 레이블이 조금 다릅니다. `edge`는 같은 레이블의 Buy & Hold와 비교한 값이라 학습 기간끼리 비교할 수 있습니다.

| 열 | 뜻 |
|---|---|
| `edge` | 정확도 − Buy & Hold(항상 Up) 정확도 |
| `mde` | 이 평가구간으로 확인할 수 있는 최소 차이. 독립 표본 N/s개, α 5%(양측), 검정력 80%: 2.8 · √(p(1−p)/(N/s)) |
| `cv_acc`, `cv_gap` | 학습구간 교차검증 정확도와 평가 정확도의 차이. 크면 표본이 적어 하이퍼파라미터가 잡음에 맞춰진 것 |
| `n_train`, `n_train_independent` | 학습 행 수와 독립 표본 근사(n_train / s) |
| `beats_bh`, `significant` | edge > 0인 예측기간 비율, edge > mde인 예측기간 비율 |

읽는 법: 곡선이 학습 기간에 따라 오르면 데이터가 더 있으면 나아질 여지가 있습니다. 평평하거나 회색 띠(±mde, 잡음 범위) 안에 머물면 데이터를 늘리는 것만으로는 나아지지 않습니다. 긴 학습 기간이 오히려 나쁘면 시장 성격이 바뀌어(비정상성) 오래된 데이터가 방해가 되는 것일 수 있습니다.

`summary.md`와 `lc_sample_size.csv`에는 엣지 d를 확인하는 데 필요한 독립 표본 수 (1.96 + 0.84)² · p(1−p) / d²와, 예측기간 s로 그만큼 쌓는 데 걸리는 기간도 들어 있습니다(정확도 50% 근처).

| 엣지 d | 독립 표본 | 일간 s = 1 | 일간 s = 5 | 주간 s = 1 | 일간 s = 20 | 주간 s = 4 |
|---|---|---|---|---|---|---|
| 5%p | 약 785 | 3.1년 | 15.6년 | 15.1년 | 62년 | 60년 |
| 3%p | 약 2,180 | 8.7년 | 43년 | 42년 | 173년 | 168년 |
| 2%p | 약 4,900 | 19.5년 | 97년 | 94년 | 389년 | 377년 |

## 논문과 다르게 한 것

- **교차검증 fold**: 시간 순서 블록으로 나누고, 레이블 구간 (t, t+s]가 검증 블록과 겹치는 학습 표본을 버립니다(purged k-fold). 무작위 fold는 겹치는 레이블 때문에 검증 정확도가 부풀어 과적합된 하이퍼파라미터를 고릅니다. 학습/평가 경계에서도 레이블이 평가구간에 걸치는 마지막 s개 학습 표본을 버립니다.
- **SMA · EMA · ATR**: 가격 수준 대신 종가 대비 비율로 씁니다. 한 지수를 16년 쓰면 평가구간 가격이 학습구간 범위를 벗어나 표준화가 의미를 잃기 때문입니다(정보는 같습니다).
- **ANN**: Matlab trainscg 대신 Adam + 검증 손실 early stopping(patience 10)이고, 종목 50개 평균 대신 지수 하나라 초기값 운을 줄이려고 시드 5개를 평균합니다.
- **표본**: 종목 50개의 평균 ± 표준편차가 아니라 지수 하나라 칸마다 값이 하나이고 잡음이 큽니다(`acc_se` 참고).

## 결과 (코스닥150, `results/kosdaq150/`)

아래는 논문 모델(SVM · ANN · kNN) 결과입니다. 추가 모델(트리 계열 · 계량 모형)은 아직 코스닥150 데이터로 돌리지 않았습니다.

기본 설정(진입 1일 지연, 거래비용 10bp, 무위험금리 0)으로 돌린 결과입니다. 전체 표와 그림은 `results/kosdaq150/`에 있습니다(일별 예측 중 그리드 쪽은 15MB라 빼고, walk-forward 예측만 넣었습니다).

**그리드 (평가 2023-02-03 ~ 2026-08-31, 871거래일, 학습 OHLC/종가 1,740일 · 종가 2010~ 3,109일)**
- 정확도가 Buy & Hold(항상 Up)를 넘는 칸이 드뭅니다. 72칸 평균 정확도는 2 클래스에서 B&H보다 2.5~5%p, 3 클래스에서 5~9%p 낮습니다. B&H를 넘는 칸의 비율은 SVM 4~18%, ANN 21~31%, kNN 10% 안팎입니다.
- 평가구간에서 윈도우를 골라도(논문 Table X 방식, 낙관적) B&H를 확실히 넘는 것은 s = 1~5일의 일부뿐이고, s ≥ 15에서는 대부분 B&H보다 낮습니다.
- "n ≈ s가 최고" 패턴은 재현되지 않습니다. n ≈ s 칸의 윈도우 내 순위는 평균 3.5~5위/8(무작위면 4.5)입니다. 다만 종가 전용 SVM · ANN은 예측기간이 길수록 좋은 윈도우도 길어지는 경향(순위상관 0.4~0.9)이 약하게 보입니다.
- 정확도 표준오차(`acc_se`)가 약 5.5%p라 칸 사이 차이 대부분이 잡음 범위입니다.

**walk-forward (n = s, 매년 재학습, 거래비용 · 지연 포함)**
- 예측기간 1~30을 동일가중한 포트폴리오는 어느 모델도 B&H Sharpe를 넘지 못합니다.
  - `close_long`, 2013~2026: B&H Sharpe 0.25 · CAGR 3.1% · MDD −59%. 가장 나은 ANN 롱온리는 Sharpe 0.22 · CAGR 2.3% · MDD −44%.
  - 2019~2026 공통 구간: B&H 0.23. ANN 롱온리는 OHLC 0.22, 종가 전용(같은 기간) 0.22, 종가 전용(2010~ 학습) 0.18.
- 롱숏(논문 방식)은 대부분 Sharpe가 0 근처이거나 음수입니다.
- ANN 롱온리는 수익률은 B&H와 비슷하지만 평균 비중이 약 0.5~0.6이라, 변동성(약 20% vs 29~34%)과 MDD가 작습니다. 예측력보다는 비중을 줄인 효과에 가깝습니다.
- s = 1에서는 논문 지표 Sharpe가 B&H의 두 배(ANN · kNN 0.5 안팎 vs 0.25)이지만, 하루 지연과 거래비용을 넣은 포트폴리오에서는 대부분 사라집니다.

**종가 전용 vs OHLC, 학습 기간**
- 같은 날짜에서 종가 전용(`close_short`)과 OHLC(`ohlc_short`)는 그리드 · walk-forward 모두 차이가 잡음 수준입니다. 이 데이터에서는 고가 · 저가가 추가 정보를 거의 주지 않았습니다.
- 2010년부터 학습(`close_long`)하면 그리드에서 롱온리 성과가 조금 나아지지만(n ≈ s 칸 SVM Sharpe 중앙값 0.32 vs 0.08 · 0.16), 상당 부분은 모델이 Up을 더 자주 예측해 B&H에 가까워진 결과입니다. 그 대신 종가 전용으로 표본 밖 백테스트를 2013년부터 할 수 있어 검증 기간이 7.7년에서 13.8년으로 늘어납니다.
